# Harish Bandi — Personal Portfolio

Dark-premium responsive personal portfolio built with React, Vite, Framer Motion and Lucide icons.

## Run locally
Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the Vite local URL, usually http://localhost:5173.

## Included
- Profile details and professional links from the latest resume
- Skills, StyleKart and FreshMart projects
- Voidmain Technologies software development internship
- Java Full Stack Development training at Sathya Technologies
- MCA, B.Sc, Intermediate and SSC education
- Uploaded profile photo
- Latest resume PDF at `public/Harish-Resume.pdf`

## Build
```bash
npm run build
npm run preview
```

## Deploy
Push to GitHub and import into Vercel. Build command: `npm run build`; output directory: `dist`.
